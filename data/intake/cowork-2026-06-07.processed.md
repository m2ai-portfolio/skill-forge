Generate `about-me.md`, `brand-voice.md`, and `working-preferences.md` context files for a Claude Cowork workspace from a short intake interview.

- **[a] Effort:** S — pure LLM synthesis from a 10-question interview; no API integrations needed.
- **[b] Dependencies:** Claude API, Cowork workspace folder schema (`~/Claude-Workspace/context/`).
- **[c] Value:** 4 — Every Cowork client needs these files in week 1; generating them reduces 90-min setup to ~10 min and is deliverable #1 in the Launchpad.

**Routing:** BUILT — `skills/cowork-context-file-builder/`

### 2. `cowork-launchpad-assessment`
Skill that takes a client's tool stack (CRM, accounting, comms) and vertical as input and outputs a Discovery Sprint deliverable: capability audit + 3-workflow recommendation with setup complexity estimates.

- **[a] Effort:** S — structured prompt synthesis; output is a markdown doc (the $1,500 Discovery Sprint artifact).
- **[b] Dependencies:** Claude API, brief tool-stack questionnaire. No MCP needed.
- **[c] Value:** 4 — The Discovery Sprint is the low-risk entry offer ($1,500 fixed). Automating the deliverable makes it repeatable and defends margin.
- **[d] Why now or never:** Without a repeatable output template the Discovery Sprint becomes a bespoke consulting engagement that can't scale beyond one concurrent client.

**Routing:** BUILT — `skills/cowork-launchpad-assessment/`

### 3. `cowork-skill-generator`
Given a workflow description (goal, inputs, process steps, output format, trigger, connectors), generate a properly formatted Claude Cowork skill file following the canonical skill anatomy.

- **[a] Effort:** S — prompt template + output formatter; the skill file anatomy is well-defined.
- **[b] Dependencies:** Claude API. Optional: Cowork GitHub community library for style reference.
- **[c] Value:** 4 — Skills Packs are productized at $500–$3K each. This compresses custom skill authoring from 30+ min to 5 min per skill and is the engine for volume delivery.
- **[d] Why now or never:** The Real Estate Skills Pack (idea #7 below) requires authoring 5 skills in week 3. Without this, that's 2.5 hrs of manual formatting.

**Routing:** BUILT — `skills/cowork-skill-generator/`
